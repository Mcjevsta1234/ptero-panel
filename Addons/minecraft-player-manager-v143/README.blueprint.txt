BLUEPRINT INSTALLATION

Downloaded addon: Minecraft Player Manager 1.4.3
Author: 0x7d8

(!) BLUEPRINT:
Make sure blueprint is installed fully using the steps from
  https://blueprint.zip/docs/?page=getting-started/Installation

 - Installation of the addon:
  1. Copy minecraftplayermanager.blueprint to your pterodactyl folder (usually /var/www/pterodactyl)
  2. Run
    blueprint -install minecraftplayermanager
  3. Done!

 - Updating the addon:
  1. Copy the new minecraftplayermanager.blueprint to your pterodactyl folder
  2. Run
    blueprint -install minecraftplayermanager
  3. Done!

 - Removing the addon: (only if you want to remove the addon, not update)
  1. Run
    blueprint -remove minecraftplayermanager
  2. Done!
